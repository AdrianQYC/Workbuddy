# Workbuddy

Workbuddy 是一个轻量、本地优先的个人工作台。当前版本包含“每日计划”“每日英语”和“知识文库”三个模块，后续可以继续扩展其他工作台功能。

当前不需要 Node.js 或后端，直接用浏览器运行，数据保存在本机浏览器本地数据里。

## 当前模块：每日计划

- 左侧工作台模块入口负责在每日计划、每日英语和知识文库之间切换，并在底部保留全局数据备份
- 当前模块的统计、添加区和内容列表集中显示在右侧工作区
- 今天、日程、中期、生日、搜索五个工作栏
- 今天、日程、中期支持全部、未完成、已完成、已取消筛选
- 日程栏显示所有日程类任务，并按今天、未来、过去、未安排折叠分组
- 普通日程任务如果过期未完成，打开 Workbuddy 时会自动顺延到今天
- 一次性日程任务可以取消并记录原因，取消后会保留原日期记录且不再顺延
- 中期目标支持截止日和节点任务
- 中期节点会按日期进入今天视图，也可以在搜索中查找
- 中期目标默认折叠，点击箭头后显示节点
- 子任务全部完成后，母任务自动完成
- 点击母任务完成圆圈，可以一键完成母任务和全部子任务
- 生日栏支持记录年份、公历/农历生日、闰月和备注，年份只作信息备注，不参与提醒计算
- 生日记录按一年内的月日顺序排列，离当前日期最近的下一条生日会用绿色背景提示
- 生日距离当前日期 30 天内时，会自动生成一个中期生日准备任务
- 普通任务、中期目标和节点任务都可以修改标题、日期和重要性
- 普通、重要、紧急三档重要性，并用柔和背景色区分
- 任务支持拖拽排序
- 全局搜索支持关键词、日期、重要性、状态组合筛选
- 手机和电脑自适应布局
- Workbuddy JSON 备份导入/导出，适合配合坚果云手动同步
- PWA manifest 和基础离线缓存

## 当前模块：每日英语

- 每日英语内部包含今日、复习、词库、词组、搜索五个工作栏
- 支持多个词库，当前雅思托福为试用词库，考研英语和专业英语先保留空壳
- 每日单词会从当前选择的词库中抽取
- 每个词库单独统计已学和总数
- 词库支持未学、已学、全部分类，并支持 A-Z 和学习日期排序
- 单词支持音标、释义、英文例句、例句中文释义、我的备注、美式发音、英式发音和标记已学
- 复习页会从当前词库已学单词中抽词，先只显示英文，点击认识/不认识后显示完整内容
- 每个词条记录认识次数/复习次数
- 词组支持近义、反义、形近、义近、同主题和自定义积累

## 当前模块：知识文库

- 知识文库内部包含分类、新建、导入、回收站四个工作栏
- 默认进入分类页，系统自带“未分类”文件夹
- 支持新建分类、重命名分类、折叠展开分类、删除分类
- 支持从“新建”栏或分类内新建 Markdown 文档
- 点击已有文档标题会进入同一个编辑器，并显示为“编辑文档”状态
- 文档编辑页支持编辑/预览切换，预览会按常用 Markdown 格式展示阅读效果
- 文档支持标题、正文和多分类归类；一篇文档可以同时属于多个分类，但正文只保存一份
- 支持导入 `.md` 和 `.txt` 文件，导入后进入编辑页继续选择分类并保存
- 支持单篇文档导出为 `.md`
- 支持分类导出为 `.zip`，压缩包内按分类文件夹保存 `.md` 文档
- 分类页支持批量处理：可以同时选择文件夹和文档，批量导出、批量删除，或把选中文档批量移动到目标分类
- 删除文档或分类会先进入回收站，回收站支持恢复和彻底删除
- 回收站支持批量处理，可以批量恢复或彻底删除
- 分类页支持文档搜索，搜索范围包括标题、正文和分类名称
- 分类和文档支持手动排序；在手动排序模式下按住 `☰` 拖动钮上下拖拽即可调整顺序

## 运行

日常使用可以双击桌面 `Workbuddy` 快捷方式。它会打开一个可见的黑色终端窗口作为本地服务，并用 Chrome 应用窗口打开：

```text
http://localhost:5173/index.html
```

桌面快捷方式现在指向项目目录里的可见窗口版：

```text
启动Workbuddy.cmd
```

使用期间请保持黑色终端窗口打开。用完后先关闭 Workbuddy 页面，再手动关闭黑色终端窗口即可停止本地服务。

也可以直接打开 `index.html`，但不建议长期这样使用；本地数据、离线缓存和桌面应用更适合固定通过 `localhost:5173` 访问。

## 数据说明

- 新版数据键：`workbuddy.tasks.v1`
- 生日数据键：`workbuddy.birthdays.v1`
- 英语学习数据键：`workbuddy.english.v1`
- 知识文库数据键：`workbuddy.knowledge.v1`
- 旧版 `daily-planner.tasks.v1` 会自动迁移到新版数据键
- 导出文件名格式：`Workbuddy-YYYYMMDD-HHMM.json`
- 导出的 JSON 里包含 `tasks`、`birthdays`、`english` 和 `knowledge`，私人数据都不会上传到 GitHub
