# Workbuddy

Workbuddy 是一个轻量、本地优先的个人工作台。当前版本先实现“每日计划”模块，后续可以继续扩展其他工作台功能。

当前不需要 Node.js 或后端，直接用浏览器运行，数据保存在本机浏览器 `localStorage`。

## 当前模块：每日计划

- 今天、本周、中期、收集箱、搜索五个工作栏
- 今天、本周、中期、收集箱支持全部、未完成、已完成、已取消筛选
- 普通日程任务如果过期未完成，打开 Workbuddy 时会自动顺延到今天
- 一次性日程任务可以取消并记录原因，取消后会保留原日期记录且不再顺延
- 中期目标支持截止日和节点任务
- 中期节点会按日期进入今天和本周视图
- 中期目标默认折叠，点击箭头后显示节点
- 子任务全部完成后，母任务自动完成
- 点击母任务完成圆圈，可以一键完成母任务和全部子任务
- 普通任务、中期目标和节点任务都可以修改标题、日期和重要性
- 普通、重要、紧急三档重要性，并用柔和背景色区分
- 任务支持拖拽排序
- 全局搜索支持关键词、日期、重要性、状态组合筛选
- 手机和电脑自适应布局
- Workbuddy JSON 备份导入/导出，适合配合坚果云手动同步
- PWA manifest 和基础离线缓存

## 运行

在项目目录启动本地静态服务器：

```powershell
python -m http.server 5173
```

然后打开：

```text
http://localhost:5173
```

也可以直接打开 `index.html`，但离线缓存和添加到主屏幕需要通过本地服务器访问。

## 数据说明

- 新版数据键：`workbuddy.tasks.v1`
- 旧版 `daily-planner.tasks.v1` 会自动迁移到新版数据键
- 导出文件名格式：`Workbuddy-YYYYMMDD-HHMM.json`
