# Workbuddy

Workbuddy 是一个轻量、本地优先的个人工作台。当前版本包含“每日计划”“每日英语”“知识文库”和“商品比价”四个模块，后续可以继续扩展其他工作台功能。

当前不需要 Node.js 或后端，直接用浏览器运行，数据保存在本机浏览器本地数据里。

## 当前模块：每日计划

- 左侧工作台模块入口负责在每日计划、每日英语、知识文库和商品比价之间切换，并在底部保留全局数据备份
- 当前模块的统计、添加区和内容列表集中显示在右侧工作区
- 今天、日程、中期、周期、生日、搜索六个工作栏
- 今天、日程、中期支持全部、未完成、已完成、已取消筛选
- 日程栏显示所有日程类任务，并按今天、未来、过去、未安排折叠分组
- 普通日程任务如果过期未完成，打开 Workbuddy 时会自动顺延到今天
- 一次性日程任务可以取消并记录原因，取消后会保留原日期记录且不再顺延
- 中期目标支持截止日和节点任务
- 中期节点会按日期进入今天视图，也可以在搜索中查找
- 中期节点按节点日期从早到晚显示；没有日期的节点排在后面
- 中期目标默认折叠，点击箭头后显示节点
- 子任务全部完成后，母任务自动完成
- 点击母任务完成圆圈，可以一键完成母任务和全部子任务
- 普通任务、中期目标、节点任务和周期任务支持“备注”；备注里可以写多行内容，也可以用“清单”按钮添加可勾选分项
- 备注清单的勾选状态和任务完成状态互不联动，适合记录采购、准备事项等分项进度
- 周期栏支持每天、每周、每隔 N 天和每月某日的周期任务
- 周期任务会在应该执行的日期显示到“今天”页，但不计入“日程”和“总完成”
- 周期任务单独保存完成、未完成、跳过记录，默认折叠日历，只显示该任务从开始到今天的总计
- 每个周期任务展开后都能独立选择开始日期和结束日期，按所选时间段查看总结和日历
- 打开 Workbuddy 时，过去该做但没有记录的周期日期会自动记为未完成；当天未完成不会提前算失败
- 生日栏支持记录年份、公历/农历生日、闰月和备注，年份只作信息备注，不参与提醒计算
- 生日记录按一年内的月日顺序排列，离当前日期最近的下一条生日会用绿色背景提示
- 生日距离当前日期 30 天内时，会自动生成一个中期生日准备任务
- 普通任务、中期目标和节点任务都可以修改标题、日期和重要性
- 普通、重要、紧急三档重要性，并用柔和背景色区分
- 日程任务、中期目标和周期任务在对应手动排序场景下支持按住 `☰` 拖动排序
- 全局搜索支持关键词、日期、重要性、状态组合筛选，关键词会匹配标题、备注和清单项
- 手机和电脑自适应布局
- Workbuddy JSON 备份导入/导出，适合配合坚果云手动同步
- PWA manifest 和基础离线缓存

## 当前模块：每日英语

- 每日英语内部包含今日、复习、词库、词组、搜索五个工作栏
- 支持多个词库，当前雅思托福为试用词库，考研英语和专业英语先保留空壳
- 每日单词会从当前选择的词库中抽取
- 每个词库单独统计已学和总数
- 词库支持未学、已学、全部分类，并支持 A-Z 和学习日期排序
- 单词支持音标、释义、英文例句、例句中文释义、我的备注、美式发音、英式发音和标记已学
- 复习页会从当前词库已学单词中抽词，先只显示英文，点击认识/不认识后显示完整内容
- 每个词条记录认识次数/复习次数
- 词组支持近义、反义、形近、义近、同主题和自定义积累；每个词组可以设置默认词性和词组备注，每个单词可以单独记录词性、中文释义和使用备注

## 当前模块：知识文库

- 知识文库内部包含分类、新建、导入、回收站四个工作栏
- 默认进入分类页，系统自带“未分类”文件夹
- 支持新建分类、重命名分类、折叠展开分类、删除分类
- 支持从“新建”栏或分类内新建 Markdown 文档
- 点击已有文档标题会进入同一个编辑器，并显示为“编辑文档”状态
- 文档编辑页支持编辑/预览切换，预览会按常用 Markdown 格式展示阅读效果
- 文档支持标题、正文和多分类归类；一篇文档可以同时属于多个分类，但正文只保存一份
- 支持导入 `.md` 和 `.txt` 文件，导入后进入编辑页继续选择分类并保存
- 支持单篇文档导出为 `.md`
- 支持分类导出为 `.zip`，压缩包内按分类文件夹保存 `.md` 文档
- 分类页支持批量处理：可以同时选择文件夹和文档，批量导出、批量删除，或把选中文档批量移动到目标分类
- 删除文档或分类会先进入回收站，回收站支持恢复和彻底删除
- 回收站支持批量处理，可以批量恢复或彻底删除
- 分类页支持文档搜索，搜索范围包括标题、正文和分类名称
- 分类和文档支持手动排序；在手动排序模式下按住 `☰` 拖动钮上下拖拽即可调整顺序

## 当前模块：商品比价

- 用于手动积累购物平台收藏和购买记录，不自动抓取平台数据
- 支持自建一级分类和二级分类；只选择一级分类时，会显示该一级分类下的全部商品
- 分类区采用左侧目录式布局，一级分类和二级分类分区显示，商品搜索和排序集中在商品列表上方
- 商品条目默认折叠，只显示商品名和当前最低单价对应的平台
- 展开商品后可以填写数量单位，并新增购买日期、本次名称、平台、总价、数量、国标号和备注
- 平台使用固定下拉选项：淘宝、京东、拼多多、抖音、盒马、阿里巴巴
- 国标号记录在单次购买记录里，界面固定显示 `GB/T` 前缀，只需填写后面的数字；不填写时记录里不显示
- 总价默认单位为元；数量单位是自由文本，例如 `g`、`支`、`ml`，不填写时记录里不显示单位
- 单价按总价除以数量自动计算；金额和数量按两位小数保存，极小单价会显示四位小数
- 复杂包装可以先换算成同一个数量单位后录入，例如把 `12 瓶 × 325ml` 记为 `3900ml`，包装信息写入备注
- 商品支持按名称顺序和手动排序；手动排序模式下按住 `☰` 拖动调整顺序
- 一级分类和二级分类标签支持按住标签主体拖动排序，二级分类只在当前一级分类内排序
- 搜索支持商品名、本次名称、平台、国标号、备注和分类路径，点击搜索结果会跳转到对应分类并展开商品
- 支持导出商品比价 Excel；导出范围可选全部、当前视图或自定义一级/二级分类，表格包含购买记录明细、商品汇总和导出说明

## 运行

日常使用可以双击桌面 `Workbuddy` 快捷方式。它会打开一个可见的黑色终端窗口作为本地服务，并用 Chrome 应用窗口打开：

```text
http://localhost:5173/index.html
```

桌面快捷方式现在指向项目目录里的可见窗口版：

```text
启动Workbuddy.cmd
```

使用期间请保持黑色终端窗口打开。用完后先关闭 Workbuddy 页面，再手动关闭黑色终端窗口即可停止本地服务。

也可以直接打开 `index.html`，但不建议长期这样使用；本地数据、离线缓存和桌面应用更适合固定通过 `localhost:5173` 访问。

## 数据说明

- 新版数据键：`workbuddy.tasks.v1`
- 生日数据键：`workbuddy.birthdays.v1`
- 周期数据键：`workbuddy.recurrences.v1`
- 英语学习数据键：`workbuddy.english.v1`
- 知识文库数据键：`workbuddy.knowledge.v1`
- 商品比价数据键：`workbuddy.shopping.v1`
- 旧版 `daily-planner.tasks.v1` 会自动迁移到新版数据键
- 导出文件名格式：`Workbuddy-YYYYMMDD-HHMM.json`
- 导出的 JSON 里包含 `tasks`、`birthdays`、`recurrences`、`english`、`knowledge` 和 `shopping`，私人数据都不会上传到 GitHub
